# Filter hooks

Generated by `mahout-devtools`. Do not edit by hand; run `composer hooks:generate`.

Every hook name is a `public const` on a `Hooks` class; its `@action` or `@filter` docblock tag decides which of the two documents the entry lands in.
The other kind lives in `actions.md`.

| Constant | Hook | Arguments | Since | Description |
|---|---|---|---|---|
| `ENTRIES` | `mahout/assets/entries` | `list<EntryPoint> $entries`, `EntryContext $context` | 1.0 | Filters the entry list resolved for one context, immediately before it is registered. A filter may add, remove or reorder entries. |
